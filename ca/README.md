# CA: Criptografía Avanzada

El examen es de preguntas cortas, sin test. Este test de práctica entrena los modos de operación del cifrado por bloques: ECB, CBC, CFB, OFB y CTR. Las preguntas comparan los modos entre sí, y sus explicaciones dicen cómo funciona cada uno y en qué se diferencia de los demás. Cada pregunta tiene 3 opciones y una sola correcta. Un fallo resta 1/3 de un acierto.
